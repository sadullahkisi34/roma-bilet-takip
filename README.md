# Roma - Real Madrid bilet takibi

`biglietti.asroma.com` uzerindeki Regular Tickets bolumunu 5 dakikada bir kontrol eder,
sonucu Telegram'a gonderir. GitHub Actions uzerinde calisir; bilgisayarin acik olmasi gerekmez.

Gerekli secret'lar: `TG_BOT_TOKEN`, `TG_CHAT_ID`.

Durdurmak icin: Actions sekmesi > "Roma bilet kontrol" > sag ustten "Disable workflow".
